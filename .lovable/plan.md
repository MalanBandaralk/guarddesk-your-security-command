# Enrich the GuardDesk Homepage

## Goal
Turn the current concise homepage into a fuller, conversion-focused product page while preserving GuardDesk’s calm, professional B2B design.

## Changes
- Improve the top navigation with a working mobile menu and links to the expanded sections.
- Strengthen the opening product preview with clearer live-operation context and attention states.
- Add focused sections for operations managers, field teams, finance teams, and clients.
- Add a practical capability overview covering deployment, attendance, patrols, incidents, payroll, billing, and profitability.
- Add database-driven-pricing messaging without inventing plan prices, plus a clear workspace/demo call to action.
- Add a concise security and multi-tenancy section, Sri Lanka-first/configurable positioning, and frequently asked questions.
- Expand the footer with useful navigation and access links.
- Keep all claims honest; avoid fabricated customers, testimonials, statistics, compliance claims, or pricing.
- Preserve existing GuardDesk tokens, restrained green accent, neutral surfaces, compact corners, and responsive layouts.

## Technical Details
- Refactor the homepage into small local presentation sections rather than one oversized component.
- Use existing Button, BrandMark, icons, semantic colors, and TanStack links.
- Keep one H1 and retain route-specific social/search metadata.
- Verify desktop and mobile rendering, navigation, page anchors, browser errors, and TypeScript.
